# Nova Table

**Good Food. Good Moments.**

A responsive, static food-brand concept website for Nova Table. Built with semantic HTML, standalone CSS and vanilla JavaScript, with no framework or build step.

## Preview

GitHub Pages: https://patu-art.github.io/NOVA/

## What's included

- Responsive landing page with mobile navigation
- Menu cards with working category filters
- Brand story and brand-value sections
- FAQ built with accessible native disclosure elements
- Validated menu-idea form with an honest, local-only copy interaction
- Keyboard focus styles, skip link, semantic landmarks, and reduced-motion support
- Search and social metadata
- No fake ordering flow, checkout, reviews, phone number, or unconfirmed business claims

## Important project note

Nova Table is presented as an early-stage food-brand concept. Menu items are illustrative, and menu availability, prices, opening hours, service area, delivery arrangements, and ordering are not confirmed. The idea form runs in the browser only; it does not send or store submissions.

## Run locally

Open `index.html` in a browser. No dependencies or build tools are required.

## File structure

- `index.html` — page structure and content
- `style.css` — design system, responsive layout, illustrations, and interaction states
- `script.js` — mobile navigation, menu filters, idea-form validation/copy, and current year
- `assets/favicon.svg` — local vector favicon

## Accessibility and responsive checks

The page includes a skip link, labelled form fields, semantic sections, visible focus states, native keyboard-operable FAQ controls, accessible filter states, responsive layouts, and reduced-motion handling. Check the site at 320px, 360px, 390px, tablet, and desktop widths before treating it as production-ready.
